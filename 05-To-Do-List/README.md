# 📝 Ganesh's To-Do List Manager

A terminal-based **To-Do List Manager** built using **Python**. This application allows users to manage daily tasks by adding, viewing, completing, and deleting tasks. All tasks are stored permanently in a **JSON file**, so your data is preserved even after closing the program.

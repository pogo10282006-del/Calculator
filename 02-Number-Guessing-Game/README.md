# 🎯 Ganesh's Number Guessing Game

A fun terminal-based **Number Guessing Game** built using **Python**. Test your guessing skills by selecting a difficulty level and trying to find the secret number in the fewest attempts.

---

## 📸 Preview

```text
==================================================
🎮 GANESH'S GUESSING GAME
==================================================

Choose Difficulty

1. Easy (1-50)
2. Medium (1-100)
3. Hard (1-500)
4. Impossible (1-1000)

Guess the number (1-100): 42

📉 Too Low!

Guess the number (1-100): 75

📈 Too High!

Guess the number (1-100): 63

🎉 Congratulations!
🥳 You guessed the number correctly!
📊 Total Attempts: 3
🏆 New Best Score!
```

# 🏦 Ganesh's Bank Management System

A terminal-based **Bank Management System** built using **Python**. This project allows users to create a bank account, securely manage transactions using a PIN, deposit and withdraw money, check account balance, and view transaction history.

---

## 📸 Preview

```text
============================================================
🏦 GANESH'S BANK MANAGEMENT SYSTEM
============================================================

1. Create Account
2. Deposit Money
3. Withdraw Money
4. Check Balance
5. Transaction History
6. Exit

Enter Choice:
```

- 🏦 Create New Bank Account
